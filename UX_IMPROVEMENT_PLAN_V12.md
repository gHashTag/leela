## Executive Summary

Cycle 7 seeded an `ActivityScreen` and cycle 8 partially polished it (`relativeTime.ts`, placeholder avatar code, `RefreshControl` import), but the screen still:
1. **Caps replies at 10 own posts** — the Firestore `in` query is hard-capped instead of batched.
2. **Does not actually fetch avatars** — `fetchAuthorAvatars` exists but is never called.
3. **Does not show relative timestamps** — `formatRelativeTime` is imported but not rendered.
4. **Does not wire pull-to-refresh** — `RefreshControl` is imported but not attached to the list.
5. **Has no visible error state** — Firestore errors are captured but users see only an empty list.

This cycle finishes the polish.
