# Leela UX Continuous Improvement Plan v5

> Generated by autonomous loop on 2026-08-07 (cycle 2). Focus: trust & offline resilience → game screen clarity → accessibility completeness.> Continues from `UX_IMPROVEMENT_PLAN_V4.md`.

## Executive Summary

After cycle 4’s foundation work (Dynamic Type, PostCard bug, subscription localization, dead-code cleanup), cycle 5 shifts to **user trust and onboarding friction**.

**New critical findings:**
1. **Offline/guest mode is buried** — `WelcomeScreen` shows only "Online"; `Hello` hides offline behind a native `Button` with `color="transparent"`. Competitors (Holy Wander, Sacred Ganges, Ram Mandir Devotion, The Power of Istighfar) treat offline/guest as a primary CTA.
2. **WhatsNewModal is already wired** — `useWhatsNewModal` uses semver and opens the modal on version upgrade, but there is no first-run discovery and no "what's new" translations beyond the default.
3. **Accessibility gaps remain** — `PostCard` action icons and `GameBoard` cells lack labels; `FeedFilter` chips are good but the "new replies" badge is missing entirely.
4. **Game screen still stacks 15+ cards** — no progress yet on collapsing into a "Today" summary.
5. **iOS wrapper drift persists** — LaunchScreen is iPhone 7-sized; privacy strings are present but minimal.

## Competitor UX Benchmark (cycle 2)

| App / Source | Pattern we can borrow |
|---|---|
| [Waking Up](https://screensdesign.com/showcase/waking-up-meditation-wisdom) | Dark minimal aesthetic, "free if you can’t afford it" trust signal, theory/practice split |
| [Calm](https://screensdesign.com/showcase/calm) | Yearly plan reframed as "per month", onboarding checklist, mood check-ins |
| [Insight Timer](https://screensdesign.com/showcase/insight-timermeditate-sleep) | Late paywall after investment, robust filtering, post-session reflection |
| [Holy Wander](https://holy-wander.damangames.center/) | Guest mode as primary onboarding option, offline mode for rural/commuter users |
| [Sacred Ganges](https://sacred-ganges-celebration.damangames.center/) | Basic gameplay without internet, festival/event calendar for retention |
| [The Power of Istighfar](https://meta00s.com/share/p/the-power-of-istighfar) | "Continue as guest to save your progress", streaks & reminders |
| [Apple — Onboarding for Games](https://developer.apple.com/app-store/onboarding-for-games/) | Teach through 3–5 short tutorials, let players choose rules now/later, replayable help |
| [Board Game Tutorial Case Study](https://medium.com/@ramlijohn/board-game-tutorial-mobile-app-a-ux-design-case-study-10649bdf7dc0) | Interactive demos over manuals, control over pacing, no blank screens |

**Key patterns to adopt this cycle:**
- **Guest/offline CTA on the first screen** (not buried in auth).
- **Deferred account creation** — let users roll once before sign-up.
- **First-run changelog** so returning users see what changed.
- **No blank states / no unlabeled icon buttons** in community feed.
