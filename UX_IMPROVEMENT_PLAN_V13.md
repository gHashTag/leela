## Executive Summary

Cycle 8 completed the Activity screen polish. Cycle 9 shifts to **monetization UX**, the highest remaining business-impact area. The current paywall only shows monthly/annual individual plans and has no recovery path for users whose trial ends or who cancel.

**New critical findings:**
1. **No family plan upsell** — Apple Family Sharing / household subscriptions are an established high-LTV lever; the current screen shows only individual SKUs.
2. **No win-back surface** — after the 2-report trial cap or a cancellation, the only path is the same paywall; there is no tailored offer or value reminder.
3. **No experiment decision UI** — `recommendExperiment('gameTodaySummary')` exists but is not surfaced to developers/PMs in-app, so the experiment cannot be actioned without reading logs.
4. **Paywall lacks social proof / loss aversion** — proven patterns (RevenueCat, MWM) show anchoring, best-value badges, and loss-aversion copy lift conversion 15–20%.

## Competitor UX Benchmark (cycle 9)

| Source | Pattern to borrow |
|---|---|
| [RevenueCat Paywall Rules / family sharing](https://www.revenuecat.com/docs/tools/paywalls/creating-paywalls/rules) | Toggle family vs. individual package stack at runtime |
| [Apple Win-Back Offers](https://developer.apple.com/help/app-store-connect/manage-subscriptions/set-up-win-back-offers/) | Native win-back sheet surfaced when subscription lapses |
| [MWM paywall best practices](https://mwm.ai/guides/paywall-design-best-practices) | Three placements: onboarding, contextual, retention/win-back |
| [Airbridge subscription experiments](https://www.airbridge.io/en/blog/decoding-subscription-monetization-proven-strategies-of-100-paywall-and-pricing-experiments) | Annual plan framing, family/lifetime upsells, 15–20% conversion lift |
| [RevenueCat pricing psychology](https://www.revenuecat.com/blog/growth/subscription-pricing-psychology-how-to-influence-purchasing-decisions/) | Anchoring, scarcity, loss aversion, endowment effect |
| [Cancellation-flow examples](https://blog.funnelfox.com/cancellation-flows-examples-and-best-practices/) | Reason survey → matched save offer → clean confirmation |
| [Statsig experiment decision framework](https://www.statsig.com/updates/update/ship-decision-framework) | Explicit recommendation banner, metric lift table, Make Decision CTA |

**Key patterns to adopt this cycle:**
- Add a **family plan card** on `SubscriptionScreen` that appears when RevenueCat offerings include a package with `family` in its identifier.
- Use **anchoring** by ordering family → annual → monthly, with a "Best for households" badge.
- Add a **trial-ended / win-back banner** on `GameScreen` and `ProfileScreen` for non-Pro users who have hit the 2-report cap.
- Add a developer-facing **Experiment Status** helper/screen so `gameTodaySummary` can be actioned without reading logs.
- Add localized copy for all new strings.
