# Leela UX Continuous Improvement Plan v7

## Executive Summary

After cycle 6 replaced the overloaded game screen with a single `GameTodaySummary` card, cycle 7 polishes the core dice interaction and adds an experiment flag so we can validate the new layout before shipping it to 100% of users.

**New critical findings:**
1. **Dice lacks iOS haptics** — it only calls `Vibration.vibrate()`, which produces a generic buzz on Android and is unsupported / low-quality on iOS.
2. **Dice visual target is too small** — the cube is 65×65 pt with a 44×44 minimum touch target; real board-game apps use 80–100 pt dice with extra padding.
3. **First-time players see no cue to roll** — an empty board and a static dice cube give no instruction when `history` is empty.
4. **GameTodaySummary change is irreversible without a flag** — there is no local or remote toggle to compare the new summary layout against the original stacked cards.

## Competitor UX Benchmark (cycle 4)

| Source | Pattern to borrow |
|---|---|
| [Android Haptics design principles](https://developer.android.com/develop/ui/views/haptics/haptics-principles) | Use clear, action-oriented haptics; avoid generic `vibrate()` |
| [iOS HapticRicochet / WWDC21](https://developer.apple.com/videos/play/wwdc2021/10278/) | Pair haptics tightly with animation; `prepare()` generators before the interaction |
| [DSDice — haptic dice collisions](https://www.dashstack.tech/ds-dice.html) | Pattern-based feedback at exact physics moments |
| [Empty States in React Native](https://medium.com/@didemsahin1789/never-leave-users-guessing-loading-states-empty-states-in-react-native-e124c7685ca0) | Icon + title + CTA for first-run empty states |
| [RevenueCat Experiments / offering metadata](https://www.revenuecat.com/docs/tools/experiments-v1/configuring-experiments-v1) | Use Offering metadata or local flags to A/B UI variants |

**Key patterns to adopt this cycle:**
- Cross-platform haptic utility with iOS Taptic Engine support and Android fallback.
- Larger dice visual (80 pt) with `hitSlop` and retained 44×44 minimum touch target.
- `FirstRollHelper` card that explains "Tap the dice to roll" and disappears after the first move.
- Local experiment flag `gameTodaySummary` (default `true`) that can be toggled via AsyncStorage for A/B validation.
