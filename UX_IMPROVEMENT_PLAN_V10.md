# Leela UX Continuous Improvement Plan v10

> Generated by autonomous loop on 2026-08-07 (cycle 7). Focus: data export productionization + Activity/Notifications screen seed + experiment decision helper.
> Continues from `UX_IMPROVEMENT_PLAN_V9.md`.

## Executive Summary

After cycle 6 added community filters, an unread-replies badge, and experiment analytics, cycle 7 turns two seeds into production-ready features: data export currently shares raw JSON as a message, and there is no screen where users can see *who* replied to *which* report. We also formalize the `gameTodaySummary` experiment decision rule so we can remove the legacy layout once the data supports it.

**New critical findings:**
1. **Data export shares raw JSON as a message** — it is hard to save, ugly in chat apps, and may be truncated by some share targets.
2. **No Activity/Notifications screen** — the badge is a signal, but users cannot see a list of replies without manually scanning every post.
3. **Experiment decision is undefined** — no rule for how long or how many exposures are needed to remove the legacy stacked-card layout.
4. **Haptic native dependency is still not installed** — `react-native-haptic-feedback` remains in `package.json` but not in `node_modules`/pods.

## Competitor UX Benchmark (cycle 7)

| Source | Pattern to borrow |
|---|---|
| [react-native-share file sharing](https://github.com/react-native-community/react-native-share/issues/411) | Share JSON as a real `.json` file from cache/temp directory, clean up after sharing |
| [A/B test decision framework](https://firebase.google.com/docs/ab-testing/ab-concepts) | Pre-define primary metric, guardrails, minimum runtime, then ship/kill based on data |
| [Stream activity feed deep-link](https://getstream.io/activity-feeds/docs/react-native/notification-feeds/) | Notification payload carries `target` + `comment` IDs for contextual deep-link |
| [Spotify risk-aware decisions](https://engineering.atspotify.com/2024/03/risk-aware-product-decisions-in-a-b-tests-with-multiple-metrics/) | Ship only if treatment is superior on success metrics and non-inferior on guardrails |

**Key patterns to adopt this cycle:**
- Write JSON export to a temp file and share it via `react-native-share` (or system `Share` with `file://`/`content://` URI).
- Add a minimal `ActivityScreen` listing replies to the user's posts, with deep-link to `DetailPostScreen`.
- Add an experiment decision helper that recommends keep/remove once exposures > threshold.
