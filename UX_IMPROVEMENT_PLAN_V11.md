# Leela UX Continuous Improvement Plan v11

> Generated by autonomous loop on 2026-08-07 (cycle 8). Focus: Activity screen polish — avatars, relative timestamps, pull-to-refresh, batching beyond 10 posts.

## Executive Summary

After cycle 7 shipped an Activity screen seed, cycle 8 polishes it into a trustworthy notifications surface. The current screen is capped at 10 own posts due to Firestore `in` limits, shows no relative timestamps, and has no pull-to-refresh. These gaps make it feel like a static list rather than a live conversation hub.

**New critical findings:**
1. **Activity screen is capped at 10 own posts** — Firestore `in` queries support only 10 values, so users with more posts miss replies on older reports.
2. **No relative timestamps** — users cannot tell whether a reply is from 2 minutes or 2 days ago.
3. **No pull-to-refresh** — stale state is not recoverable without leaving and re-entering the screen.
4. **Avatars are not resolved** — every row shows the default avatar because we do not fetch commenter profile photos.

## Competitor UX Benchmark (cycle 8)

| Source | Pattern to borrow |
|---|---|
| [Strava-style activity feed](https://vp0.com/blogs/strava-activity-feed-clone-react-native) | Virtualized `FlatList`, pull-to-refresh, memoized cards, header row with avatar + timestamp |
| [Stream React Native Activity Feed](https://getstream.io/activity-feeds/sdk/react-native/) | Avatar + name + timestamp header, compact relative time, real-time updates |
| [Intl.RelativeTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/RelativeTimeFormat) | Locale-aware relative time without extra deps |
| [Firestore `in` batching](https://stackoverflow.com/questions/70851638/firestore-how-to-handle-more-than-10-in-equalities) | Chunk into ≤10 parallel `onSnapshot` subscriptions, merge client-side by doc ID |

**Key patterns to adopt this cycle:**
- Batch Firestore `in` queries into 10-item chunks and merge results client-side.
- Add `Intl.RelativeTimeFormat`-based `formatRelativeTime()` utility tied to `i18n.language`.
- Show relative timestamp on each Activity row.
- Add pull-to-refresh (`RefreshControl`) to re-fetch the latest comments.
- Resolve commenter avatars from `Profiles` collection.
