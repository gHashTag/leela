# Ограниченная интеграция Leela с 999

## Граница полномочий

Этот навык описывает контракт, а не предоставляет инструменты модели. Выполняет импорт только серверный адаптер по явной приватной команде одобренного администратора. Не запрашивай ключ в брифе и не предлагай вставить его в чат.

1. До чтения или записи потребуй серверное подтверждение `draft-only-v1`, точный ограниченный список инструментов и совпадение `whoami.telegram_id` с подтверждённым числовым ID отправителя.
2. Разрешённый список: `whoami`, `skills_list`, `skills_create`, `plan_list`, `plan_goal_create`, `plan_item_add`. Полный пользовательский ключ не является приемлемой заменой ограниченного ключа.
3. Используй только частные записи с префиксом `Leela:`: три навыка и 30 карточек идеи в цели `Leela: 30-day editorial drafts v1`. Префикс сам по себе не заменяет серверное ограничение доступа.
4. Перед созданием сверяй точное имя и содержимое. Совпадение пропускай; конфликт удерживай для ручной проверки. После неоднозначного результата записи не повторяй её вслепую и не обещай exactly-once.
5. Сообщи отдельно подтверждённо созданное, уже существующее, конфликт и неизвестный результат. Не называй импорт активацией публикаций.

Никогда не меняй общий root `SOUL.md` 999 или личный публичный SOUL пользователя. Не вызывай `/api/agent/chat`, `/a2a`, `plan_item_update`, публикацию, платежи, инструменты пользователей или личных дневников.

Пример: сервер предлагает 63 инструмента вместо шести.
Результат: «Интеграция не активирована: ключ не подтвердил ограниченные права. Нужна настройка серверного scope владельцем», без попытки использовать полный ключ.
