# @leela/mobile

The board on a phone. It carries no rule of its own: every move goes through
`advance` in `@leela/engine`.

## Running it

```bash
npx expo run:ios          # builds ios/ and launches on a simulator
```

`ios/` is generated by `expo prebuild` and gitignored. After changing
`app.json`, regenerate it with `--clean` — prebuild does not rewrite the bundle
identifier of a project that already exists, and the app installed under the
Android one for a while because of that.

## The walk through the app

`npx vitest run` is the suite. Detox is the walk: it opens the app on a
simulator and uses it the way a player does.

```bash
npx expo prebuild --platform ios       # once, or after changing app.json
npm run e2e:build                      # xcodebuild, several minutes
npm run e2e                            # 14 flows
```

Needs a Mac, a simulator, `applesimutils` (`brew install wix/brew/applesimutils`)
and Metro running against **this** app — a packager serving another project on
8081 gives the walk an app with no controls in it, which reads like the controls
being gone.

**It cannot run in CI.** Every job here is `ubuntu-latest`. So it is a command a
person runs, and that is said here rather than in a job that would be skipped.

### What it is for

The unit suites own the rules — `@leela/engine` has 334 and this app has none of
its own. What they cannot see is the wiring, and every defect this app has given
up was found by running it:

- it installed under the Android bundle identifier;
- the winning square's teaching was shown to somebody who had not begun;
- the Save button was clipped to nothing and then made invisible;
- the board was forgotten on every launch;
- the keyboard covered the button that keeps what was just typed;
- and what the player is playing for was kept in memory, so the game asked
  again every time.

The last two were found by the walk itself, on its first honest run.

### The die is not seeded

A player needs a six to enter the board, and the obvious way to make that
certain is a launch argument only a test passes. A code path nobody who plays
the game takes is a code path nobody maintains, so the walk taps the die until
the board says it is on it, with a stated bound: forty throws without a six is
about one run in two thousand, and it fails saying so rather than hanging.
