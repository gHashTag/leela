# Leela UX Continuous Improvement Plan v4

> Generated by autonomous loop on 2026-08-07. Focus: accessibility & polish → game screen clarity → trust & offline resilience → monetization nudges.
> Based on audit of `/Users/playra/leela-src/leela` (React Native 0.70.4 iOS/Android app) and competitor analysis.

## Executive Summary

The app has strong retention features (streaks, recaps, welcome-back) and AI depth, but suffers from:

1. **Game screen clutter** — 15+ overlapping cards collapse visual hierarchy.
2. **Accessibility violations** — global `allowFontScaling={false}` disables iOS Dynamic Type; most icon buttons lack labels.
3. **Production bugs** — `PostCard` reads `item` before declaration; subscription screen uses unlocalized hardcoded errors.
4. **Dead code & drift** — PlansDetail audio player is commented out; offline mode is hidden; iOS deployment target/version numbers are inconsistent.
5. **Community trust gaps** — no "new replies" badge, no report topic filters, no follow feature (all already planned in v3).

**Key UX patterns to adopt:** intention-before-play, calm/minimal aesthetic, larger tap targets, offline-first fallback, VoiceOver support, adaptive layouts.
