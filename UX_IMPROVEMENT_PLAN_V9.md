## Executive Summary

After cycle 5 closed cross-platform toast and iOS privacy gaps, cycle 6 moves into **community trust features**. The public feed currently has only `newest` / `mostDiscussed` / `myPosts` filters, and there is no signal when a user's own reports receive new replies. These gaps hurt retention and make the community feel passive rather than conversational.

**New critical findings:**
1. **No topic filtering in the public feed** — users cannot follow specific themes (plan numbers, intentions, hashtags) beyond the global feed.
2. **No reply notification signal** — post authors have no in-app cue that someone commented on their report.
3. **Filters are hard-coded** — adding a new filter requires editing two files (`postFeedFilter.ts` + `FeedFilter`).
4. **Game screen experiment has no analytics exposure tracking** — we cannot tell whether the `gameTodaySummary` flag actually affects behavior.

## Competitor UX Benchmark (cycle 6)

| Source | Pattern to borrow |
|---|---|
| [Mastodon hashtag menu #31393](https://github.com/mastodon/mastodon/issues/31393) | In-context hashtag/topic actions: mute, report, filter |
| [Bluesky stackable moderation](https://bsky.social/about/blog/03-12-2024-stackable-moderation) | User-chosen moderation/filter labels, transparent report flow |
| [Activity feed UX Pattern](https://uxpatternsguide.com/patterns/activity-feed/) | Tab-bar badge + activity feed for replies/mentions |
| [Threaded discussion UX Pattern](https://uxpatternsguide.com/patterns/threaded-discussion/) | Preserve parent context and branch depth in replies |
| [A/B test analytics best practice](https://docs.mixpanel.com/docs/tracking-methods/sdks/react-native/react-native-flags) | Track experiment exposure when a variant is rendered, persist assignments in AsyncStorage |

**Key patterns to adopt this cycle:**
- Extend `PostFeedFilter` with topic filters based on `plan` number / `planText` keywords.
- Add a lightweight **"My reports with new replies"** filter to the feed.
- Add a **tab-bar badge** on the community tab driven by an unread-replies counter.
- Track `gameTodaySummary` experiment exposure with an analytics event when the variant is rendered.
