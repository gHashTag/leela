## Executive Summary

Cycle 11 completed the backend ingestion of cancellation survey responses and added a `DiagnosticsScreen`. Cycle 12 uses that diagnostics surface to finalize the oldest active UX experiment: `gameTodaySummary`. The experiment was seeded in cycle 6, tracked in cycles 7–9, and now needs a decision path that can actually change the shipped UI.

**New critical findings:**
1. **Recommendation exists but cannot be applied** — `experimentDecision.ts` returns `keepSummary`/`keepLegacy`/`insufficientData`, but nothing wires that result into the feature flag.
2. **Legacy cards are still shipped** — `GameScreen` branches on the `gameTodaySummary` flag; the legacy branch (`DailyVerse`, `WeeklyRecap`, `RollHistory`, `LastMoveReplay`, `ResumeLastGame`) still exists and adds maintenance surface.
3. **No one-button "apply winner"** — product/dev teams must manually toggle AsyncStorage to act on a recommendation.
4. **No exposure count** — `experimentStatus.ts` hardcodes `exposures: 0` because the tracker only stores the latest session exposure.

## Competitor UX Benchmark (cycle 12)

| Source | Pattern to borrow |
|---|---|
| [Statsig make a decision](https://docs.statsig.com/en/experiments/ending/make-decision) | Apply winner as new default, schedule rollout phases, keep holdback |
| [Airship feature flags](https://www.airship.com/docs/guides/experimentation/feature-flags/) | Bayesian winner declaration → roll out winner → archive flag → remove legacy code |
| [Firebase Remote Config A/B Testing](https://firebase.google.com/docs/ab-testing/abtest-config) | Declare leader, roll out winning variant to all users |
| [Feature flag lifecycle](https://flagshark.com/docs/best-practices/flag-lifecycle/) | Stabilize at 100% for 7–14 days, then remove flag code |

**Key patterns to adopt this cycle:**
- Add `applyExperimentRecommendation(name)` that reads `recommendExperiment` and sets the corresponding feature flag.
- Add a **dev-only** "Apply recommendation" button in `DiagnosticsScreen`.
- Add a **dev-only** "Remove legacy cards" switch that hides the legacy branch components entirely (preparation for flag cleanup).
- Track total exposure count so the recommendation helper has real signal.
- Add tests for apply/cleanup helpers.
