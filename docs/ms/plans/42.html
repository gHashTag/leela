42. Pesawat api (Agni Loka)

Agni adalah manifestasi yang sangat jelas tentang kelahiran semula kitaran abadi intipati ketuhanan yang sama. Api ialah roh, jiwa, dan badan pada masa yang sama. Alam semesta kita dan apa yang berkembang di dalamnya, termasuk manusia, adalah hasil api Tuhan. Dalam ungkapan simbolik dia ditunjukkan dengan tiga wajah, mewakili tiga api—pavak, api elektrik; pavamana, api yang dihasilkan oleh geseran; dan suchi, api para dewa, juga dikenal di Rig Veda sebagai vaishvanara, api magnet hidup yang melanda semua galaksi. Perkataan vaishvanara sering digunakan untuk diri sendiri.

Pemain yang mendarat di Agni-loka bersedia untuk mengambil bentuk. Agni adalah Tuhan Api; Api adalah manifestasi tenaga yang teruk. Di dalam badan, api ini adalah kehidupan itu sendiri. Ia adalah cinta dan keselamatan. Itu adalah keselamatan manusia terhadap kerosakan binatang buas pada masa dia tinggal di Gua. Tetapi api hanyalah satu manifestasi Agni. Dengan udara dan air ia adalah salah satu daripada tiga punca pemejalan bumi dan dengan itu merupakan induk bentuk. Kebakaran juga merupakan punca cahaya, yang merupakan gabungan warna. Oleh itu api adalah punca kedua-dua warna dan bentuk—intipati dunia yang luar biasa.

Kebakaran adalah manifestasi kasar tenaga, kenderaannya. Pemain yang mendarat di sini memahami bahawa tubuhnya juga hanyalah kenderaan. Oleh sebab itu, api dianggap sebagai penghubung antara manusia dan Tuhan. Semua ritual keagamaan merangkumi kehadiran Agni, saksi abadi. Dan kerana dewa api ini hanyalah ungkapan sifat semula jadi manusia, pemain mengetahui bahawa penipuan diri adalah mustahil. Saksi sentiasa ada. Pemain yang akan mengambil bentuk melakukannya dengan pengetahuan bahawa peranan yang dipikulnya mesti mematuhi perintah undang-undang planet. Sebarang penyimpangan menipu diri sendiri, dan aliran tenaga ke bawah pasti akan mengikuti penipuan diri.

Menurut mitologi Hindu, Agni memutuskan untuk meneroka penciptaan itu. Dia mengambil bentuk seperti udara dan mengembara ke seluruh muka alam semesta dengan daun teratai. Tetapi selepas satu masa dia menjadi letih dan mencari tempat untuk berehat. Tidak lama kemudian dia melihat sarang di muka perairan abadi. Hai sarang dia menyebarkan api. Perairan itu adalah isteri Varuna, satu lagi manifestasi Agni. Api-keinginan Tuhan untuk wanita-wanita ini dinyalakan, dan tidak lama lagi mereka bersedia untuk kesatuan. Air mani beliau jatuh dan menjadi bumi. Inilah api yang dia tanam di tengah sarang, dan planet ini adalah keturunannya.

Sains moden (iaitu.. Sains Barat) kini percaya bumi telah bermula sebagai bola api (Agni). Air menyejukkan permukaan planet, membolehkan kehidupan timbul. Walaupun sekarang, api tetap berada di inti planet ini, seperti yang ditunjukkan oleh gunung berapi yang menjijikkan batu lebur dari kedalaman bumi. Sekiranya API dalaman ini mati, Kehidupan akan lenyap dari planet ini.
