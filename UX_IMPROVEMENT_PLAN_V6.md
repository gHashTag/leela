# Leela UX Continuous Improvement Plan v6

> Generated by autonomous loop on 2026-08-07 (cycle 3). Focus: game screen clarity → iOS native health → monetization nudges.
> Continues from `UX_IMPROVEMENT_PLAN_V5.md`.

## Executive Summary

After cycle 5’s trust & offline work, cycle 6 attacks the **#1 reported UX weakness**: the game screen stacks 15+ cards, collapsing visual hierarchy and burying the core dice/board action.

**New critical findings:**
1. **Game screen is the highest-impact problem** — DailyVerse, WeeklyStreak, StreakMilestone, WeeklyRecap, WelcomeBack, ResumeLastGame, IntentionPrompt, StreakJournal, UxFeedback, LastMoveReplay, RollHistory all compete for attention before the dice and board.
2. **Cards are individually well-designed but collectively noisy** — each has its own color, emoji header, and padding; there is no information hierarchy.
3. **iOS launch screen is still iPhone 7-sized** — hardcoded 375×667 frame; will look wrong on modern devices and may trigger App Store review issues with recent SDKs.
4. **Paywall lacks a yearly nudge** — packages are rendered as a flat list with no "Best value" anchoring or monthly equivalent.

## Competitor UX Benchmark (cycle 3)

| App / Source | Pattern to borrow |
|---|---|
| [Apple Games app / WWDC25](https://developer.apple.com/videos/play/wwdc2025/215/) | Card-first "Today" dashboard, event/activity cards, one-tap re-entry into gameplay |
| [Fanatics app case study](https://sgx.studio/case-study/designing-the-fanatics-app-from-foundation-to-future-vision/) | "For You" personalized feed instead of static grid |
| [Blask Games single-game view](https://blask.com/blog/quick-tour-the-game-view-in-blask-games/) | Modular, reorderable summary cards with a clear KPI header |
| [Discourse mobile chat badges](https://github.com/discourse/discourse/pull/25438) | Segmented tab-bar badges, color-coded urgency, capped counts |
| [Courier notification center UX](https://www.courier.com/blog/in-app-notification-center-design/) | Meaningful badges, capped counts (`9+`), pair badge with bold list text |
| [iOS launch screen best practices](https://www.avanderlee.com/xcode/launch-screen/) | Auto Layout + size classes, avoid hardcoded frames, simple close-to-first-screen layout |
| [Apphud / RevenueCat paywall guides](https://apphud.com/blog/design-high-converting-subscription-app-paywalls), [RevenueCat guide](https://www.revenuecat.com/blog/growth/guide-to-mobile-paywalls-subscription-apps) | Default to annual, "Best value" badge, monthly equivalent anchoring, 2–3 options max |

**Key patterns to adopt this cycle:**
- **"Today" summary card** on the game screen — one card replaces DailyVerse, WeeklyStreak, WeeklyRecap, RollHistory, LastMoveReplay, ResumeLastGame when appropriate.
- **Adaptive iOS LaunchScreen** with Auto Layout and the existing `SplashIcon` asset.
- **Yearly-plan nudge** in the subscription flow: pre-select annual, badge it "Best value", show monthly equivalent.
